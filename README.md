## About the Project

Salon Queue Management System helps customers
join salon queues and track their waiting time.

It allows receptionists to manage customers,
barbers to manage services and owners to manage
salon operations.

## Technologies Used

- React
- Vite
- TypeScript
- Tailwind CSS
- Node.js
- Express
- SQLite
- Socket.IO

## Main Features

- Customer queue registration
- Service selection
- Barber selection
- Live queue tracking
- Reception Dashboard
- Barber View
- Waiting Area TV
- Owner Settings
- English and Gujarati support
